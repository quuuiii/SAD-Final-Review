# SA&D Final Review

Interactive, responsive, single-file Systems Analysis & Design study app for course Chapters 1–5.

## Features
- Bilingual chapter notes, flashcards and searchable topics
- Past exam practice and explanations
- Timed mock examination, performance dashboard and radar visualization
- Quick quiz, cheat sheet, bookmarks and local browser storage
- Light and dark themes

## Open
Open `index.html` in a modern browser.

## Publish using GitHub Pages
Open repository **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/(root)**, then Save. The expected website address is https://quuuiii.github.io/SAD-Final-Review/ once GitHub Pages publishes it.

> The prior exam scans and their explanations are study material; verify any uncertain transcriptions against the original paper. User progress is saved in the browser's local storage, not synchronized to GitHub.
